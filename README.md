# SistemaBD_Taller_herreria_Fuereno

## Descripción

Este proyecto consiste en la creación e implementación de una base de datos para un taller de soldadura y herrería artística perteneciente a mi abuelo y mi padre. El sistema está diseñado para organizar y administrar de manera eficiente la información del negocio, como clientes, trabajos realizados, materiales utilizados, costos y fechas de entrega.

La base de datos busca apoyar las actividades diarias del taller, reducir errores en el manejo de la información y facilitar la consulta y el registro de datos relacionados con los servicios que ofrece el negocio.

## Motivación

La motivación de este proyecto surge de la necesidad de mejorar la organización y gestión de la información en un negocio familiar que forma parte de mi comunidad. Al aplicar los conocimientos adquiridos sobre bases de datos a una situación real, se busca aportar una solución práctica que optimice los procesos del taller y demuestre la importancia del uso de la tecnología en pequeños negocios locales.
