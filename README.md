# SistemaBD_Taller_Herreria_Fuereno

## Descripción
Este proyecto consiste en el diseño e implementación de una base de datos para un taller de soldadura y herrería artística, perteneciente a un negocio familiar.

El sistema está orientado a organizar y administrar de manera eficiente la información del taller, incluyendo clientes, trabajos realizados, materiales utilizados, costos y fechas de entrega.

La base de datos busca apoyar las actividades diarias del negocio, reducir errores en el manejo de la información y facilitar la consulta y registro de datos.

---

## Motivación
La motivación de este proyecto surge de la necesidad de mejorar la organización y gestión de la información en un negocio familiar que forma parte de mi comunidad.

A través de la aplicación de conocimientos en bases de datos a una situación real, se busca aportar una solución práctica que optimice los procesos del taller y resalte la importancia del uso de la tecnología en pequeños negocios locales.
